Data Visualization Class

An archive of all of the projects worked on for IGME-460: Data Visualization. Please note that formality was not a requirement for these submissions, so some of them may contain jokes or focus on strange subjects. Also note that these graphs were optimized for larger screen resolutions, so they're best viewed on a computer screen.

Project 1: Basic Bar Chart

A bar chart detailing the usage rates of the Pokémon Ruby/Sapphire/Emerald OverUsed metagame throughout different years. The year can be chosen using a dropdown menu, and the chart displays the rates of each of the top 40 Pokémon of that year. Also, clicking on one of the bars takes you to a detailed analysis of how that Pokémon works in battles. The data was sourced directly from Smogon, the primary hub for competitive Pokémon, and filtered by me to only include high-level players.

Project 2: Variety Hour

A variety of charts that depict different data on a number of topics, such as marine life, fictional words, and oversharing details about my sleep schedule. All of this data was made up by me, but still treated as if it was real data and given the proper treatment and care visualizing it. The embeded Observable page contains links to each of these visualizations.

Project 3: Detailed Bar Chart

This bar chart is similar to that of Project 1, but contains a number of extra features and a different dataset. It focuses on the Pokémon Diamond/Pearl/Platinum OverUsed metagame, and only uses the data from March 2024, which was the newest data at the time. In exchange, the data itself is a lot more in-depth. It contains every Pokémon that was used in the tier, which can be filtered and scrolled using a brush at the side. Each Pokémon's bar also shows a tooltip when hovered over, which displays information like its typing, ability, stats, and ranking.
