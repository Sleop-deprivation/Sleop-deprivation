Leo Schindler-Gerendasi's IGME 330 Page

This is an archive of my classwork for IGME 330: Rich Media Web App Development. It contains links to my four major projects for this class. Unlike IGME 235, this class didn't require its own home page, but for convenience's sake I created one in the style of my IGME 235 home page.

Project Links:

A simple Technobabble generator, which generates random combinations of technology-themed words. The main draw of this assignment was that its layout is adaptive, with different layouts for phones, tablets, and computers.

An audiovisualizer, themed around a simple night sky. The intensity of the moon and the size of the stars increase based on the chosen song's frequency. Of further note is that all of the assets are original: the sprites were made by me, and the songs that can be chosen are either taken from Bait & Tackle or are original pieces made by me.

An exercise in transpiling TypeScript into ES5 JavaScript, which also laid the baseline for my first portfolio. The content is very outdated given that it was made over a year ago, but the important part is that the website still works after its code was transpiled.

A simple web app that allows the user to view information about different New York State Parks, mark any of them as favorites, and have that data persist through reloads. This app uses the Mapbox API to display the map of New York State, as well as the Firebase API to keep count of aggregate favorites in a seperate webpage, which can be accessed here.
